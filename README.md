# BTL-_-XLTHS-_-PTIT
Bài tập lớn môn Xử lý tín hiệu số tại Học viện Công nghệ Bưu chính Viễn thông. Mô phỏng hệ thống mã hóa và giải mã tín hiệu Dual-Tone Multi-Frequency - công nghệ nền tảng của hệ thống phím bấm điện thoại. Hệ thống bao gồm bộ phát tín hiệu với giao diện GUI trực quan và bộ thu giải mã sử dụng cấu trúc Filter Bank với các bộ lọc FIR Window-based.
